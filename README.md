# 🎯 Number Guessing Game

## 📌 Project Overview

An interactive Number Guessing Game developed using Java and Web Technologies.

The player tries to guess a randomly generated number between 1 and 100 while receiving hints after each attempt.

---

## ✨ Features

### ☕ Java Version

✅ Random Number Generation

✅ Attempt Counter

✅ High / Low Hints

✅ Replay Option

### 🌐 Web Version

✅ Interactive User Interface

✅ Real-Time Feedback

✅ Responsive Design

✅ Modern Sage Green Theme
